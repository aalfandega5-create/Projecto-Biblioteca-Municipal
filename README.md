# Biblioteca Municipal  Sistema informático simples, baseado em consola, desenvolvido em Java para auxiliar na gestão de livros, utilizadores, empréstimos e devoluções de uma Biblioteca Municipal.  ## Disciplina  Introdução a Algoritmos e Programação  ## Linguagem  Java  ## Funcionalidades  - Registo de livros - Consulta do catálogo - Pesquisa de livros por título - Pesquisa de livros por autor - Registo de utilizadores - Listagem de utilizadores - Empréstimo de livros - Devolução de livros - Estatísticas dos empréstimos - Validação de dados e tratamento de erros  ## Estruturas de dados  O sistema utiliza:  - Arrays (vetores) para armazenamento dos dados dos livros; - Arrays (vetores) para armazenamento dos dados dos utilizadores; - Uma matriz para controlar a relação entre utilizadores e livros emprestados.  Os dados são armazenados temporariamente em memória durante a execução do programa.  ## Requisitos  - Java JDK 17 ou superior  ## Estrutura do projecto  ```text biblioteca-municipal-java/ │ ├── src/ │   └── Main.java │ └── README.md
